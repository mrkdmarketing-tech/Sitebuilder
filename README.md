# MRKD Platform

MRKD Marketing's internal platform, replacing Retool. It lives inside MRKD's GoHighLevel sidebar, with a direct link for phones. Ads managers get a live dashboard of their clients' ad performance on phone and desktop, with suggestions they can act on. The platform also handles client onboarding, ad approvals, billing, and GoHighLevel/LeadLabz admin.

**Status:** planning. No app code yet.
